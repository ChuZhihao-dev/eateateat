# 🍚 今天吃什么（eateateat）

一个移动优先的智能选餐助手。解决"每天不知道吃什么"的问题：按口味、预算、时间、手头食材帮你挑，还能摇一摇随机决定，并记录你吃过什么、避免重复。

---

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 🎲 智能推荐 | 综合口味、预算、做饭时长、食材多维度打分，加权随机出结果 |
| 📱 摇一摇 | 点大按钮或真的晃动手机换一批（移动端陀螺仪） |
| 🧊 冰箱食材 | 输入手头有的食材，优先推荐能用上的菜 |
| 🔁 避免重复 | 可设置 1/2/3/7 天内吃过的菜不再推荐 |
| 📝 用餐记录 | 一键记录吃了什么，支持 1–5 星评分 |
| 📊 月度统计 | 用餐次数、菜品丰富度、人均/总花费、最爱吃的菜、菜系分布 |
| 📚 菜品库 | 55 道预置菜品，支持增删改、搜索、按菜系筛选 |
| 🍜 视觉菜品 | 每道菜按菜系自动配色 + 匹配食物图标 |

**内置 55 道菜**，覆盖川菜、湘菜、粤菜、日料、韩料、西餐、轻食、面食等 16 个菜系，早/午/晚三餐均有。

---

## 🧱 技术栈

- **后端**：Node.js + Express
- **数据库**：`node:sqlite`（Node 内置，无需额外安装数据库）
- **前端**：原生 HTML / CSS / JavaScript，移动优先，无构建步骤
- **依赖**：仅 `express` 一个运行时依赖

## 🚀 快速开始

### 环境要求

- Node.js **≥ 22.5.0**（需要内置的 `node:sqlite` 模块）
- 查看版本：`node -v`

### 安装与启动

```bash
# 1. 安装依赖
npm install

# 2. 启动服务
npm start
```

启动后终端会打印两个地址：

```
  🍚 今天吃什么 已启动
  本机:   http://localhost:3000
  手机:   http://192.168.x.x:3000   (同一 WiFi 下打开)
```

### 在手机上使用

1. 确保手机和电脑连的是**同一个 WiFi**
2. 手机浏览器打开终端里打印的**手机地址**（`http://192.168.x.x:3000`）
3. 建议「添加到主屏幕」，即可像原生 App 一样全屏使用（已适配 iPhone 安全区）

### 开发模式（改动自动重启）

```bash
npm run dev
```

### 修改端口

```bash
# Windows PowerShell
$env:PORT=8080; npm start
```

## 📖 使用手册

底部有 4 个标签页：**推荐 / 菜品库 / 记录 / 统计**。

### 一、推荐（首页）

1. **选择餐段**：顶部胶囊按钮切换「早餐 / 午餐 / 晚餐 / 不限」，进入时会按当前时间自动选好。
2. **选择心情**：左右滑动点选「随便吃点 / 想清淡 / 想吃辣 / 重口味 / 想吃肉 / 想吃素 / 想喝汤 / 减脂轻食」，会立即重新推荐。
3. **展开「更多筛选」**（可折叠）：
   - **人均预算**：≤20 / ≤35 / ≤50 / ≤80 元
   - **愿意花的时间**：15 / 30 / 60 / 90 分钟内
   - **不重复吃过的**：不避开 / 1 / 2 / 3 / 7 天
   - **冰箱里有什么**：输入食材（顿号、逗号或空格分隔），例如 `鸡蛋、番茄、豆腐`
4. **点中间的大圆按钮** 🎲 换一批；手机上晃一晃也能触发。
5. **看结果**：
   - 首选菜显示在大卡片里，标注「✨ 今日首选」和匹配度
   - 下方列出的每条推荐都带推荐理由（如"用得上：鸡蛋"、"还没吃过，尝尝鲜"）
   - 点 **🍴 就吃它** 记录这一餐；点 **换一批** 重新随机
6. **下拉刷新**：在列表顶部下拉可刷新当前页。

> 如果筛选条件太严导致没有结果，系统会自动逐级放宽（先放开"避免重复"，再放开预算/耗时），并在结果上方提示。

### 二、菜品库

1. 顶部搜索框支持按**菜名 / 食材 / 菜系 / 标签**搜索。
2. 下方的菜系胶囊可快速筛选，右侧显示该菜系菜品数量。
3. 不搜索时，菜品**按菜系分组折叠**，点分组标题展开/收起。
4. 点 **＋（右下角悬浮按钮）** 或右上角「＋ 新增」添加菜品。
5. **点任意菜品**打开编辑面板，可修改后保存，或点「删除」。

**新增/编辑菜品字段**：菜名（必填）、菜系、可当哪一餐（多选）、标签（多选）、辣度（0–3）、耗时（分钟）、人均价格、主要食材。
底部编辑面板可**从顶部把手下拉关闭**。

> 标签会影响推荐打分，"辣度"和"荤/素"建议如实填写。

### 三、记录

1. 记录**按日期分组折叠**，默认展开"今天"。
2. 每条记录显示餐段、菜名、时间、价格和评分。
3. **打分**：点星星即可评分（1–5 星），评分会用于后续推荐加权——给过高分的菜更容易被推荐。
4. **删除**：在条目上**向左滑动**露出「删除」按钮并点击（桌面端直接点右侧垃圾桶图标）。
5. **下拉刷新**同步最新记录。

### 四、统计

1. 右上角可**选择月份**（默认当月）。
2. 顶部 4 张卡片：用餐次数 / 吃了多少种 / 人均花费 / 当月估算总花费。
3. 下方三个**可折叠区块**：
   - **餐段分布**：环形图展示早/午/晚占比
   - **最爱吃的菜**：本月吃的次数 Top 10
   - **菜系喜好**：各菜系占比

## 🧠 推荐算法说明

推荐分数由 `src/recommend.js` 计算，各维度加权后做**加权随机抽样**（所以每次结果不同，但更符合条件的分更高）：

| 维度 | 加分规则 |
| --- | --- |
| 心情/口味 | 每命中一个口味标签 +5；辣度不匹配 -4 |
| 预算 | 超出预算 -10；在预算内按剩余空间加分 |
| 耗时 | 超出上限 -10；越快加分越多 |
| 食材 | 每命中一样手头食材 +3；食材全齐 +2 |
| 历史评分 | 按 `(均分 - 3) × 1.5` 加权，4 分以上显示理由 |
| 新鲜度 | 没吃过的 +2；最近吃过的 -6 |

筛选流程逐级放宽，保证一定有结果：

```
① 餐段 + 预算/耗时 + 排除最近吃过的
② 放开"排除最近吃过的"
③ 放开预算和耗时限制
④ 全库随机
```

## 🔌 API 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/meta` | 心情选项、餐段选项、当前建议餐段 |
| GET | `/api/dishes` | 全部菜品 |
| GET | `/api/dishes/:id` | 单个菜品 |
| POST | `/api/dishes` | 新增菜品 |
| PUT | `/api/dishes/:id` | 修改菜品 |
| DELETE | `/api/dishes/:id` | 删除菜品（连带记录） |
| GET | `/api/recommend` | 获取推荐 |
| GET | `/api/meals` | 用餐记录（`?limit=` 默认 100） |
| POST | `/api/meals` | 记录一餐 |
| PATCH | `/api/meals/:id` | 修改评分 |
| DELETE | `/api/meals/:id` | 删除记录 |
| GET | `/api/stats` | 月度统计（`?month=YYYY-MM`） |

### `/api/recommend` 查询参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `meal` | string | 按当前时间 | `breakfast` / `lunch` / `dinner` / `any` |
| `mood` | string | `any` | `any` / `light` / `spicy` / `heavy` / `meat` / `veg` / `soup` / `lite` |
| `maxPrice` | number | 不限 | 人均预算上限（元） |
| `maxCook` | number | 不限 | 最长做饭时间（分钟） |
| `ingredients` | string | 空 | 手头食材，逗号分隔 |
| `avoidDays` | number | `2` | 多少天内吃过的排除，`0` 表示不排除 |
| `count` | number | `3` | 返回条数（最多 10） |

示例：

```bash
curl "http://localhost:3000/api/recommend?meal=lunch&mood=spicy&maxPrice=35&maxCook=30"
```

## ❓ 常见问题

**Q：手机上打不开局域网地址？**
A：确认手机和电脑在同一 WiFi；检查电脑防火墙是否拦截了 Node（首次运行 Windows 会弹窗，需选"允许"）。

**Q：推荐结果为什么每次都变？**
A：算法是加权随机抽样，更符合条件的菜被抽中的概率更高，但不会每次都一模一样——这样才不会每天吃同一道菜。

**Q：摇一摇没反应？**
A：iPhone 需要在点击按钮时授权"运动与方向访问"，点一下大按钮会触发授权弹窗。桌面浏览器不支持摇一摇，点按钮即可。

**Q：能多设备同步吗？**
A：目前数据存在本机 SQLite 文件里，局域网内多设备访问的是同一份数据。若要跨网络使用，需自行部署到服务器。

**Q：想加自己的菜？**
A：在「菜品库」里点 ＋ 添加即可，也可以直接编辑 `src/seed.js` 后删除 `data/` 重新初始化。
